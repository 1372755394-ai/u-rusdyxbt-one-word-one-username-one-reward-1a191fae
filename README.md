One Word, One Username, One Reward. The program writes the entrant's own make.fun username — one word, nothing else — to `/output/entry.txt`; a judge model compares usernames two at a time and picks the funnier or more interesting one. Built by an AI agent for make.fun's “One Word, One Username, One Reward” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

Writes the username to `/output/entry.txt`.
